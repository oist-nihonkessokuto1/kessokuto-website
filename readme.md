- 政策
  - 国家観
    - 日本を「分断された衰退途上国」と診断し、民族主義左翼の視点から「結束主義×共栄主義」を掲げ、自由主義者（令和武士）による独裁体制で再結束させる国家観。
    - 現在の議会制民主主義・自由主義体制を「分断の元凶」と位置づけ、対抗政府・並行機関（模擬議会・政府など）を「信用創造」することで、古い体制の殻を内側から破る「令和維新幕府」を樹立。結果として日本がアジア・世界における覇権を握る「第二共栄圏」を構築し、新世界秩序を主導する国家を目指す。
    - 令和維新幕府は、「第一共栄圏」を構築するためのプロトコルであり、日本がアジア・世界における覇権を握る「第二共栄圏」を構築するためのプロトコルである。
  - 何に立ち向かうのか
    - 国内：政治・社会・経済の分断と衰退（「衰退途上国」化）。  
    - 体制自体：既存の議会制・自由主義体制（これを「分断された体制」と批判）。  
    - 国際：主権侵害行為（他国・他勢力による干渉）。民族自決を尊重しつつ、共栄の理念に反する介入を非難。
    - 単なる批判ではなく、対抗政府の構築という「創る」行為で平和的・建設的に革命を起こすことを強調。歴史的ファシズムの教訓を踏まえつつ、孤立主義ではなく積極的関与を志向。 
  - 政策
    - 自治協同 — 地方自治と協同組合的な結束を推進（分断を解消し、草の根レベルの結束を強化）。  
    - 万邦共栄 — 「第二共栄圏の建設」と「新世界秩序」の実現。日本主導の共栄圏を構築し、諸国との共存・共栄を図る（日本による覇権を明言）。  
    - 経済離陸 — 衰退途上国からの脱却を目指した経済的自立・急成長政策。
